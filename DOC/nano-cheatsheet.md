#### nano cheatsheet

```
Ctrl+O   write out (save) file
Ctrl+X   exit nano
Ctrl+G   show help / get help on a command
Ctrl+K   cut current line (or marked region) into cutbuffer
Ctrl+U   paste from cutbuffer
Ctrl+C   show current cursor position (line/column)
Ctrl+\   search (replace with Ctrl+Alt+R)
Ctrl+W   search for a word
Ctrl+_   go to specified line and column
Ctrl+T   run command and inert its output
Alt+M    toggle word wrapping
Alt+/    go to specific line/column
Shift+Ctrl+Delete   delete word before cursor (chopwordleft)
arrows   move cursor
Ctrl+A   jump to start of line
Ctrl+E   jump to end of line
```
